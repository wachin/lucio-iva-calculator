Tres pantallas

Los valores de IVA excluido, IVA e IVA incluido se sincronizan automáticamente.

Tasas por país

Incluye tasas de Ecuador, Unión Europea, América y otros países.

Personalizable

Permite crear tasas propias para descuentos, recargos o impuestos especiales.

Multiplataforma

Funciona en Windows, Linux y macOS gracias a Python y PyQt6.

Tecnologías

  • Python 3
  • PyQt6 y QtSvg
  • Qt Linguist para traducciones
  • Configuración INI en la carpeta del usuario
